# Литература и ориентиры

Ниже не «доказательства проекта», а базовые источники, с которыми стоит сверять терминологию и направление исследования.

1. Cook, S. A. — The Complexity of Theorem-Proving Procedures (1971). Классическая работа о NP-полноте SAT.
2. Karp, R. M. — Reducibility Among Combinatorial Problems (1972). Классический набор NP-полных задач.
3. Davis, M.; Logemann, G.; Loveland, D. — A Machine Program for Theorem-Proving (1962). Основа DPLL.
4. Biere, A.; Heule, M.; van Maaren, H.; Walsh, T. (eds.) — Handbook of Satisfiability. Современный обзор SAT.
5. Arora, S.; Barak, B. — Computational Complexity: A Modern Approach. Теория вычислительной сложности.
6. Papadimitriou, C. H. — Computational Complexity. Классический учебник по сложности.

## Что добавлять дальше

Когда в проекте появляется конкретная техника — CDCL, BDD, XOR reasoning, proof complexity, tensor methods — к ней нужно добавлять отдельную ссылку на первичную или обзорную литературу.
