# Representation Switching в релизе 1.0

## Что именно реализовано

Рассмотрим XOR:

```text
x1 XOR x2 XOR x3 = 1
```

Его можно точно записать четырьмя CNF-клаузами.

Для обычного SAT solver это просто четыре клаузы. Для линейной алгебры это одно
уравнение над полем GF(2).

Модуль `pnp_lab/xor.py`:

1. группирует 3-CNF-клаузы по набору переменных;
2. проверяет, что четыре клаузы запрещают ровно один parity-класс;
3. только при полном совпадении создаёт `XOREquation`;
4. удаляет эти четыре клаузы из CNF-части;
5. передаёт XOR-систему в Gaussian elimination.

Если шаблон неполный или неоднозначный, преобразование не выполняется.

## Почему преобразование точное

Каждая 3-CNF клауза запрещает одно присваивание трёх переменных.

Четыре клаузы XOR-кодировки запрещают все четыре присваивания одной parity и
оставляют все четыре присваивания противоположной parity.

Поэтому множество решений до и после преобразования совпадает.

Тест `tests/test_xor.py` дополнительно проверяет эквивалентность перебором всех
восьми присваиваний трёх переменных.

## Что делает Gaussian elimination

XOR-уравнения рассматриваются как линейная система:

```text
A x = b  (mod 2)
```

Операция сложения строк — XOR.

Можно:

- обнаружить противоречие;
- получить unit equation;
- найти одно решение системы без экспоненциального перебора.

## Смешанный CNF + XOR

Если после извлечения XOR остаются обычные CNF-клаузы, solver работает совместно:

- CNF даёт unit propagation и DPLL branching;
- XOR даёт Gaussian reduction и XOR propagation;
- присваивания передаются между двумя представлениями.

Pure literal используется только для переменных, которые не участвуют в
активных XOR-уравнениях.

## Что пока не реализовано

- автоматическое распознавание XOR произвольной длины;
- CDCL;
- clause learning из XOR-конфликтов;
- полноценная decomposition с одновременными CNF и XOR hyperedges;
- BDD;
- algebraic polynomial representation;
- автоматический выбор из большого портфеля представлений.

То есть это **первый доказуемо точный switch**, а не финальная архитектура.
