# Исследовательская идея

## Polynomial Representation Switching

Исходная гипотеза:

> возможно, трудность части NP-задачи зависит не только от самой информации, но
> и от того, в каком точном математическом представлении эта информация сейчас
> находится.

Сильная версия потребовала бы доказать:

> Для любой 3-CNF размера N существует эффективно находимая последовательность
> точных переходов между представлениями, где промежуточный размер и суммарная
> работа ограничены `poly(N)`.

Если такое утверждение конструктивно доказать, это могло бы привести к
полиномиальному алгоритму для 3-SAT.

Сейчас такого доказательства нет.

## Что изменилось в 1.0

До версии 1.0 representation switching был в основном архитектурной гипотезой.

Теперь реализован первый точный переход:

```text
3-CNF XOR encoding
        |
        v
XOR linear system over GF(2)
        |
        v
Gaussian elimination
```

Это позволяет экспериментально сравнивать:

- обычный поиск по CNF;
- exact switch в линейное представление.

## Почему один успешный switch не решает P vs NP

Потому что остаются формулы:

- без XOR-структуры;
- со структурой, которую мы пока не умеем распознавать;
- со смешанными ограничениями;
- с потенциально трудными остаточными CNF.

Для решения P vs NP нужен universal polynomial guarantee, а не набор удачных
частных преобразований.

## Исследовательская стратегия

Дальше проект должен работать как цикл:

```text
новое representation
-> exact equivalence check
-> benchmark
-> adversarial search
-> counterexample
-> refinement
```

Особенно важен вопрос:

> существует ли семейство задач, которое одновременно плохо для всех доступных
> точных представлений и всех способов переключения между ними?

Если да — оно показывает границу текущей архитектуры.

Если нет на всё более сильных классах — появляется материал для новой теории,
но всё равно требуется доказательство.
