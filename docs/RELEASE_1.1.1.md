# Release 1.1.1 — проверка корректности

Версия 1.1.1 не добавляет новый solver. Она усиливает проверку уже существующего
representation switching.

Что изменилось:

- у CNF -> XOR3 появились независимо проверяемые certificates;
- добавлены property-based tests;
- добавлена exhaustive-проверка всех 256 вариантов 3-variable full-width CNF;
- случайные маленькие CNF дополнительно сравниваются с brute-force oracle;
- CI и package checks стали строже.

Главная идея простая: если проект исследовательский, недостаточно получить красивый
результат. Нужно отдельно проверять преобразования и уметь ловить ошибку тестом.

Научный статус не изменился: проект не является доказательством P=NP или P!=NP.
