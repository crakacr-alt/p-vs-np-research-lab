# Ограничения

## Проект не решает P vs NP

v0.2 — исследовательская инфраструктура.

Даже идеальная работа на всех доступных benchmark-наборах не является доказательством общей polynomial complexity.

## Hybrid solver не промышленный

Он нужен для прозрачных экспериментов. Современные CDCL solver-ы значительно сложнее и во многих задачах быстрее.

## Random 3-SAT — только одно семейство

Нельзя переносить выводы с random 3-SAT на все SAT-задачи.

Нужны структурные benchmark-семейства.

## Empirical complexity fit ограничен

R² показывает, насколько модель описывает наши конечные данные. Он не даёт теорему о пределе при n -> infinity.

## UNSAT пока не имеет proof certificate

Наш solver возвращает UNSAT после полного точного поиска, но отдельного формального сертификата пока нет.

Для важных экспериментов рекомендуется независимый solver.

## Memoization ограничена текущей канонизацией

Ключ учитывает порядок после сортировки, но не пытается распознать формулы, одинаковые с точностью до переименования переменных.

Более сильная canonicalization — отдельная исследовательская задача.
