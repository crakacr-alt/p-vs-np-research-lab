# Ограничения релиза 1.0

## 1. Проект не решает P vs NP

Работающий `CNF -> XOR` switch не является общим polynomial SAT algorithm.

## 2. XOR detection ограничен

Сейчас автоматически распознаётся точная CNF-кодировка XOR из трёх переменных,
когда четыре соответствующие клаузы присутствуют полностью.

Произвольные XOR-кодировки пока не распознаются.

## 3. Смешанная decomposition пока консервативна

Если активны XOR equations, solver не пытается независимо делить только CNF,
потому что XOR может связывать эти компоненты.

Нужен unified constraint graph.

## 4. Это не промышленный CDCL solver

DPLL/Hybrid/Switch написаны прозрачно для исследования.

Они не заменяют современные высокопроизводительные SAT solver-ы.

## 5. UNSAT proof certificates пока нет

Ответ UNSAT получается точным поиском/линейной алгеброй и проверяется
differential tests, но формальный DRAT/LRAT certificate пока не генерируется.

## 6. Empirical fit не является theorem

Ни R², ни график, ни большое число benchmark-ов не доказывают worst-case
polynomial complexity.

## 7. Hard-case search локален

Hill climbing ищет задачи, трудные для конкретной метрики текущей реализации.
Это не гарантирует нахождение глобально самого трудного экземпляра.

## 8. Brute force ограничен маленьким n

Он нужен как oracle для correctness testing, а не как production solver.

## 9. Public repository без отдельной выбранной лицензии

Наличие исходного кода в публичном репозитории само по себе не определяет
условия повторного использования. Выбор лицензии — отдельное решение владельца
репозитория.
