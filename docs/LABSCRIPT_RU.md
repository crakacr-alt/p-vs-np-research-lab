# LabScript 0.1 — русский справочник

LabScript — простой высокоуровневый язык внутри P vs NP Research Lab.
Он предназначен и для обычных программ, и для вызова точных научных движков.

Главные принципы:

- одинаковая модель программы для русского и английского синтаксиса;
- отступы и структура похожи на Python;
- кириллические имена переменных и функций разрешены;
- никакого скрытого доступа ко всему Python runtime;
- локальные модули и явно подключённые host-модули;
- воспроизводимый portable build в формате .labpkg;
- один и тот же исходник работает в CLI, Jupyter и Markdown/Obsidian.

## Выбор языка

Рекомендуется первой строкой явно указать язык.

```lab
Язык="-РУС"
```

или:

```lab
LangRule="-ENG"
```

Поддерживаются также RU/RUS/РУС и EN/ENG/АНГ.

Если директивы нет, runtime пытается определить русский режим только по
однозначным русским управляющим словам. Для библиотек и production-кода лучше
всегда писать директиву.

## Минимальная программа

```lab
Язык="-РУС"

функция квадрат(x):
    вернуть x * x

для i в диапазон(1, 6):
    печать(i, квадрат(i))
```

Английский эквивалент:

```lab
LangRule="-ENG"

function square(x):
    return x * x

for i in range(1, 6):
    print(i, square(i))
```

## Встроенные модули

### math / математика

sqrt, sin, cos, tan, log, log10, exp, floor, ceil, factorial, gcd, pi, e.

```lab
Язык="-РУС"
импорт математика

печать(математика.sqrt(81))
```

### crypto / крипто

SHA-256 и другие алгоритмы hashlib, Base64 encode/decode.

```lab
Язык="-РУС"
импорт крипто

печать(крипто.hash("данные"))
печать(крипто.decode64(крипто.encode64("привет")))
```

### sat / сат

Точный SAT-вызов через solver-ы лаборатории.

```lab
Язык="-РУС"
импорт сат

пусть результат = сат.solve(
    2,
    [[1, 2], [-1, 2]],
)

печать(результат["sat"])
```

## Свои модули

Файл helper.lab:

```lab
Язык="-РУС"

функция тройное(x):
    вернуть x * 3
```

Основной файл:

```lab
Язык="-РУС"

импорт helper
печать(helper.тройное(14))
```

Runtime ищет локальные .lab-модули рядом с программой и в LABSCRIPT_PATH.

## Host-модули

Приложение-хост может передать в LabRuntime только специально разрешённые
функции. Это основной механизм будущих интеграций с Lean, Z3, SymPy, базами,
корпоративными API и научными движками.

LabScript при этом не получает произвольный доступ к Python-объектам.

## CLI

```bash
labscript new hello.lab --lang RUS
labscript check hello.lab
labscript run hello.lab
labscript debug hello.lab
labscript build hello.lab
labscript verify hello.labpkg
labscript run hello.labpkg
labscript hash hello.lab --file
labscript encode64 "привет"
labscript decode64 "0L/RgNC40LLQtdGC"
```

Те же команды доступны через основной CLI:

```bash
pnp-lab lang run hello.lab
```

## Debug

В 0.1 debug — это детерминированный statement trace: строка, тип выполняемой
операции, номер шага и локальные значения. Интерактивные breakpoints/watchpoints
запланированы следующим слоем.

## Build

labscript build создаёт .labpkg:

- manifest.json;
- главный .lab-файл;
- только реально импортируемые локальные .lab-модули;
- SHA-256 каждого файла;
- версию языка;
- фиксированные timestamps в ZIP.

Поэтому одинаковые исходники дают одинаковые package bytes.

Build не является нативной компиляцией в exe. Нативный/WASM backend запланирован
позже, при этом исходный синтаксис менять не потребуется.

## Ограничения 0.1

Пока нет:

- классов;
- async/await;
- decorators;
- arbitrary Python imports;
- прямого file/network API;
- интерактивного debugger;
- нативного bytecode/WASM compiler.

Это сознательное ограничение первого стабильного ядра.

Step limit защищает от простых бесконечных циклов, но LabScript 0.1 не является
полным OS sandbox: тяжёлая математика всё ещё может потреблять CPU/RAM.
