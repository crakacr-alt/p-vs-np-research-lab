# Как вносить изменения

## Для нового алгоритмического улучшения

1. Сформулировать гипотезу.
2. Добавить отдельный модуль или небольшой понятный diff.
3. Добавить тест корректности.
4. Добавить benchmark/experiment.
5. Сравнить с baseline на одинаковых входах.
6. Попытаться найти случай, где улучшение не помогает.
7. Обновить документацию.

## Для новой зависимости

Обновить `docs/DEPENDENCIES.md` и объяснить:

- что это;
- зачем;
- где используется;
- что будет без неё.

## Для сильного научного утверждения

Не писать `proved`, если есть только экспериментальные данные.

Использовать формулировки:

- observed;
- measured;
- survived tested instances;
- proof candidate.
