# LabScript in Obsidian

Этот файл можно положить прямо в Obsidian vault.

Первый блок создаёт данные:

~~~lab
Язык="-РУС"

пусть числа = []
для i в диапазон(1, 6):
    добавить(числа, i * i)

печать("квадраты:", числа)
~~~

Второй блок использует состояние первого:

~~~lab
Язык="-РУС"

импорт крипто
печать("sha256:", крипто.hash(числа))
~~~

Третий блок вызывает SAT:

~~~lab
Язык="-РУС"

импорт сат

пусть результат = сат.solve(
    2,
    [[1, 2], [-1, 2]],
)

печать("SAT:", результат["sat"])
~~~

Запуск:

~~~bash
labscript markdown examples/obsidian_labscript_note.md
~~~

Результаты появятся в отдельном Markdown-файле, исходная заметка не изменится.
